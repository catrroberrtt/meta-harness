# Método (SDD)

Ciclo de especificación dirigida: especificar, validar la información, planificar, tareas, implementar, verificar, documentar, crear tickets (si hay adaptador) y actualizar el conocimiento. Incluye plantillas de especificación y de plan, la definición de «terminado» y las reglas duras como contrato configurable por proyecto. No cita ningún proyecto concreto.

## Origen

Lo aporta la instancia del proyecto; el mapa de migración vive en la instancia (parametrizacion).
