# Control de cambios

Una carpeta por cambio (`<fecha>-<tema-corto>/`) con: especificación (qué y por qué, criterios medibles), preguntas abiertas, plan, evidencia y cierre.

Puerta del piso del harness: **la especificación se valida antes de escribir código**. Las plantillas de cada documento están en el harness (`plantillas/`).
