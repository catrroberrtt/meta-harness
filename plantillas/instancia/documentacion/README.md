# Almacén de documentación

Documentación legible en `.md` (o copia exportada del almacén que use el equipo). Es el lugar donde se deja el rastro de cada cambio mientras se construye, no al final.

Cómo llega cada persona al almacén (carpeta del repositorio, carpeta de Drive o espacio de un gestor) se declara en `acceso.local.toml`, sección `[documentacion]`.
